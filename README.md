# Oxanne — Site Vitrine Officiel

Site web de présentation officiel d'**Oxanne**, la plateforme congolaise de mise en relation entre clients et artisans qualifiés (Lubumbashi, Kinshasa, Kolwezi, Goma).

## Contenu du Site
- **Présentation d'Oxanne** : Vision, mission et impact pour la RDC.
- **Corps de Métiers** : Plomberie, Électricité, Menuiserie, Peinture, Climatisation, Soudure, Maçonnerie, Carrelage.
- **Fonctionnalités Clés** : Double devise (USD et Franc Congolais FC), 0% commission cachée, messagerie instantanée, artisans 100% vérifiés.

## Déploiement sur Vercel
1. Créer un dépôt GitHub `oxanne-website` sur votre compte `20kingdev`.
2. Importer le dépôt sur Vercel :
   - Framework Preset : `Other`
   - Build Command : None
   - Output Directory : `.`
3. Le site est immédiatement accessible en ligne avec HTTPS gratuit.
